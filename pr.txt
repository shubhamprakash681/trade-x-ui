## Phase 0 — Start Here

Before writing any frontend implementation code:

1. **Read** [FrontendInstruction.md](./FrontendInstruction.md) thoroughly.
2. **Inspect** the entire backend repository (see checklist below).
3. **Create** the Phase 0 documentation.
4. **STOP** — report findings and identify backend gaps.

- [ ] OpenAPI / Swagger configuration

- [ ] `application.yml` / `application.properties`
- [ ] Docker configuration
- [ ] README files and database migrations

## Critical Rule

> Whenever you are uncertain about an API or behaviour:
>
> **STOP → Search the backend source → Inspect the controller → Inspect the DTO → Inspect the service → Inspect security → Then implement.**
>
> Never invent backend contracts.

---

## Success Criteria

The final frontend must:

1. Compile successfully and pass TypeScript checks
2. Pass lint and all tests
3. Integrate with the actual deployed backend
4. Correctly authenticate
5. Display real backend-generated market history
6. Display live simulated prices (WebSocket)
7. Execute paper trades
8. Display portfolio, holdings, and P/L
9. Support watchlist
10. Support alerts/notifications (where backend supports them)
11. Be responsive (desktop, tablet, mobile)
12. Have loading, error, and empty states throughout
13. Be maintainable with no hardcoded secrets
14. Have no invented backend endpoints
